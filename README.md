# Stylish Text Generator

A free, client-side **stylish text generator** that converts plain text into dozens of decorative Unicode font styles (bold, italic, script, gothic, double-struck, circled, full-width, and more). Perfect for social-media bios, usernames, captions, and messaging apps — no login, no server, 100% private.

## Features

- Convert any text into **stylish Unicode variants** (bold, italic, script, gothic, double-struck, monospace, circled, full-width, small caps…)
- **Live preview** — output updates as you type
- **One-click copy-to-clipboard** with toast confirmation
- **Theme switcher** with animated sparkle effects
- Fully **client-side**: your text never leaves the browser
- Zero dependencies, single HTML file, works offline

## Tech Stack

- Pure HTML5 / CSS3 / vanilla JavaScript
- Unicode character-mapping engine (mathematical, phonetic, and full-width Unicode ranges)
- No build step, no frameworks, no backend

## Quick Start

1. Clone the repo:
   ```bash
   git clone https://github.com/girishlade111/Stylish-Text-Generator.git
   cd Stylish-Text-Generator
   ```
2. Open `index.html` in any browser — or serve it locally:
   ```bash
   npx serve .
   ```
3. Type your text, pick a style, click copy.
